# SACS-1.21.1-Neoforge-fork（卡工坊 UI 版）

> 与稳定版 `SPEC-SACS-v0.032-neoforge` **同一套逻辑、同一套数据**，只重做了「角色卡编辑」界面。
> modId 仍是 `acechat`，**不能和稳定版同时放进 mods**。

## 一、界面结构

```
[角色卡：xxx ▸]            角色卡工坊 · SACS fork            [保存][重读]
                              [聊天] [形象] [文字]
                              [颜色] [管理] [剧本]
┌─ 实际样式预览（放大：形象框居中、聊天框在其下） ─┬─ 当前页字段（本页独立滚动） ─┐
│                                                   │ 右侧滚动条                   │
├─ 屏幕示意（按当前 GUI 分辨率换算相对位置） ────────┤                              │
└───────────────────────────────────────────────────┴──────────────────────────────┘
```

- **每页独立滚动**，切页记住各自位置；顶部页签 `◆` + 黄色下划线标当前页。
- **实际样式预览**：放大展示，形象框居中、聊天框在下方，只用于看样式/调色/文字。
- **屏幕示意**：16:9，按 `getGuiScaledWidth/Height` 等比，画出形象框/聊天框的实际相对位置。
- **取色**：点颜色按钮弹内嵌面板（RGBA 滑条 + HEX + 实时色块），点面板外收起，不跳旧界面。
- **选择器**：皮肤/立绘/音效预设/角色卡都是弹窗列表（滚轮 + 点选）。

## 二、六页内容

| 页 | 内容 |
|---|---|
| 聊天 | 通讯框开关、原版消息开关、行数、框宽、X/Y、背景、间距、内边距、边框、停留时长、**音效（出现/消失预设 + 音量/音调/速度/淡入淡出 + 试听 + 音效目录）** |
| 形象 | 显示名、关联玩家、皮肤、立绘（身份）＋ 照片模式/高度/缩放/宽高/偏移/透明度/亮度/蒙版/背景板/面板/边框（外观） |
| 文字 | 4 内置 + 自定义元素（内容/字号/XY/最大宽/对齐/阴影/显示/颜色/增删）＋ **默认名字颜色 + 符号颜色 + 名字颜色条目** |
| 颜色 | 调色（亮/对比/饱和/色相）、双色调、滤镜（预设/强度/混合/染色/亮度/对比/饱和/色相） |
| 管理 | 自动切卡、形象常驻/跟随、NCR 兼容、**新建卡（复制当前卡）**、重命名/删除/导出、导出配置、配置目录、**旧版配置（对照用）** |
| 剧本 | 列出全部工程 → 进入画布；打开剧本目录 |

## 三、数据归属（已对账确认）

| 数据 | 归属 |
|---|---|
| 聊天框样式（`chat` 段） | **当前客户端，全局通用，优先级最高**；卡文件不保存 `chat` |
| 形象 / 文字元素 / 调色 / 滤镜 | **每张角色卡各自保存** |
| 名字颜色条目 | **跟卡走**，条目名＝卡名，演出里这张卡发言时命中（不按玩家） |
| 符号颜色 | 放在「文字」页，仍属聊天样式 |
| 剧本工程 / 一次性记录 | `ACE_config/stage` / 存档 `acechat_stage.json` |

## 四、音效

- **预设**：出现/消失各一组，由 `CommsSoundSynth` 合成，可在「聊天」页选择。
- **自定义**：把 `new_message.ogg|mp3|wav`、`message_gone.ogg|mp3|wav` 放进 `ACE_config/sounds/`，优先于预设；改文件不用重启。
- 演出换台词时也会播「出现」音效（与普通聊天同一套开关/预设/参数）。

## 五、NCR 兼容

| | 开启（默认） | 关闭 |
|---|---|---|
| 被 NoChatReports 包成系统消息的玩家聊天 | 认回玩家聊天：名字/头像/名字颜色/切卡 | 当普通系统消息处理，不套头像、不触发切卡 |
| 识别条件 | 名字须对上已知玩家或角色卡，否则仍按系统消息 | 不识别 |
| 何时关 | — | 服务器没装 NCR，或系统消息被误认成玩家聊天时 |

## 六、自动保存

- 所有开关/滑条/颜色/选择器改动即时写入内存，并在 **400ms 防抖**后落盘；
- 顶部「保存」按钮可手动立即保存；「重读」重新加载。

## 七、构建与安装

```powershell
powershell -File _build\SACS-1.21.1-Neoforge-fork\compile.ps1   # 必须 0 错误
powershell -File _build\SACS-1.21.1-Neoforge-fork\package.ps1
powershell -File _build\SACS-1.21.1-Neoforge-fork\switch-to-fork.ps1    # 装 fork
powershell -File _build\SACS-1.21.1-Neoforge-fork\switch-to-stable.ps1  # 切回稳定版
```

> **必须在游戏关闭时切换**：脚本会检查 `java/javaw` 进程与 `latest.log` 是否 90 秒内还在写；热替换 jar 会让服务器 tick 崩 `NoClassDefFoundError`。
