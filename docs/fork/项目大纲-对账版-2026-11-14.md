# SACS-1.21.1-Neoforge-fork · 项目大纲（对账版 2026-11-14）

> **用途**：把当前模组的「功能 / 设置 / 数据 / 已知问题」摊开对账，确认后再继续改。
> **状态标记**：✅ 已实现可用　⚠️ 有缺陷/待修　⬜ 未迁移（旧界面有、新界面没有）
> **版本**：`0.1.3.12`（fork）；稳定版 `SPEC-SACS-v0.032-neoforge`

---

## 一、项目定位与边界

- Minecraft 1.21.1 + NeoForge 21.1.x，纯客户端渲染 + 服务端事件驱动。
- 三大块：**通讯 HUD**（聊天框 + 半身像）、**角色卡**（形象/文字/调色）、**剧本演出**（画布编排 + 触发播放）。
- 不做：全屏 CG、镜头控制、BGM 播放、语音。
- modId `acechat`：fork 与稳定版、旧 SACS **不能同时装**。

## 二、总体架构

```
游戏事件 ──► ServerStageTriggers ──► StageEngine 条件匹配 ──► StageState(一次性/冷却)
                    │                                        │
                    ▼                                        ▼
              选组/接收者/队列 ──► StagePayload ──► StageClient ──► StagePlayer(时间轴)
                                                                        │
                                                                        ▼
                                       CommsHud(聊天框/半身像) ◄── CommsState(队列/舞台)
                                                 │
                                      CommsConfig(当前套用的卡)
                                                 │
                     PortraitSource / CardTextures / PortraitGrade / PortraitFilters
```

| 侧 | 职责 |
|---|---|
| 服务端 | 事件采集、条件匹配、冷却/一次性、选组、下发、资源清单 |
| 客户端 | 播放时间轴、渲染、卡编辑与预览；不做触发判定 |

## 三、数据文件

| 文件 | 内容 | 写入入口 |
|---|---|---|
| `ACE_config/client.json` | 全局配置 + 当前卡快照 | `CommsConfig.save()` |
| `ACE_config/cards/<卡名>.json` | 每卡一份完整配置快照 + `character` 段 | `CommsConfig.save()/saveCard()`、`CardCharacter.write()` |
| `ACE_config/stage/<工程>.json` | 剧本工程（groups/lines/rules/canvases） | 画布 `persist()`、`StageProjects` |
| 存档 `acechat_stage.json` | 一次性/冷却记录 | `StageState.save()` |
| `ACE_config/{skins_slim,skins_classic,portraits,filters,deaths,sounds}` | 素材 | 用户放置 |

卡文件结构（要点）：

```jsonc
{
  "chat": {...}, "portrait": {...},        // 卡快照：聊天框样式、半身像几何/调色/滤镜
  "textElements": [...],                    // 文字元素（内置 4 + 自定义）
  "nameColors": [...],                      // 名字颜色条目
  "activeCard": "卡名",
  "character": { "displayName", "boundPlayer", "skin", "portrait" }
}
```

工程结构（要点）：

```jsonc
{
  "groups": [ { "id": "cv_<safe>_<hash>_1", "lines": [
      { "speaker": "卡名", "text": "...", "start": 0, "at": 0, "hold": 40, "wait": false } ] } ],
  "rules": [ { "id": "canvas", "play": ["cv_x_1"], "when": {"triggers":[...]},
               "repeat": true, "cooldown": 8, "once": "", "target": "nearby", "radius": 4 } ],
  "canvases": { "canvas": { "nodes": [...], "edges": [...] } }
}
```

时间单位：`hold/at/start/window` 为 tick（20=1 秒），`cooldown` 为秒。

## 四、新版界面结构（6 页 + 顶栏）

```
[角色卡：xxx ▸]      角色卡工坊      [保存][重读]
                        [聊天][形象][文字]
                        [颜色][管理][剧本]
```

- 颜色选择：点颜色按钮 → **右侧内嵌小面板**（RGBA 滑条 + 十六进制 + 实时色块），点面板外收起。

## 六、本轮已修问题（2026-11-14）

| 问题 | 根因 | 修法 |
|---|---|---|
| 加名字颜色不生效 | 新增条目后颜色回调没有更新已有条目 | 先建一条，再把回调绑定到这一条 |
| 改一次颜色生成多条 | 回调每次拖动都 `nameColors.add(...)` | 同上：只在新增时 add 一次 |
| 无法移除 | 只有一个“移除最后一个”，且条目已重复 | 改为**每条一个「删」**按钮 |
| 聊天页仍有名字/符号颜色 | 归属错误 | 移到「文字」页（默认名字色 + 符号色） |
| 音效不能自由选 | 只做了滑条，没有预设列表 | 出现/消失各加预设选择器（列表弹窗） |
| 卡创建缺失 | 之前改布局时删掉了 | 「管理」页恢复：输入名字 + 复制当前卡 |

## 七、对账结论（2026-11-14 已确认）

| # | 问题 | 结论 | 落地 |
|---|---|---|---|
| 1 | 页签结构 | **保持**：聊天 / 形象 / 文字 / 颜色 / 管理 / 剧本 | 已按此实现 |
| 2 | 聊天设置的归属 | **客户端全局，最高优先级，所有卡通用** | 卡文件不再写 `chat` 段；切换卡不改变聊天样式 |
| 3 | 名字颜色 | **跟角色卡走**，只绑定“这张卡”的发言（不是按玩家） | 新增条目的名字＝卡名；演出说话人＝卡名时命中 |
| 4 | 符号颜色 | **跟随名字颜色，不再单独设置** | v0.1.3.3：HUD / 原版左栏 / 注入历史三处统一 |
| 5 | 音效 | **保留自定义音效 + 预设选择** | 出现/消失各加预设选择器；自定义文件仍按 `new_message.* / message_gone.*` 覆盖 |
| 6 | 新建卡 | **复制当前卡** | 「管理」页：输入名字 → 复制当前卡 |
| 7 | 旧界面 | **保留入口**（对照/未迁移功能） | 「管理」页新增「旧版配置（对照用）」 |
| 8 | 优先级 | 按建议：P0 归属修正 → P1 卡分层 → P2 剧本页 → P3 其余 | 见第八节 |

> 补充：`nameColors` 保留在卡文件里；`chat` 段只留在 `client.json`（旧卡里的 `chat` 段下次保存时会被自动清掉，不影响使用）。
