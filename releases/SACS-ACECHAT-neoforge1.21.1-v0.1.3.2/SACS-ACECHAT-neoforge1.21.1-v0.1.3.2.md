# SACS ACECHAT NeoForge 1.21.1 · v0.1.3.2beta

> 卡工坊 UI 版（fork）首个整理后的 Beta 发布包。
> 平台：Minecraft 1.21.1 + NeoForge 21.1.x（客户端模组）
> modId：`acechat`（与稳定版/旧版 **不能同时放进 mods**）

---

## 一、安装

1. 关闭游戏；
2. 把 `SACS-ACECHAT-neoforge1.21.1-v0.1.3.2.jar` 放进：
   `E:\mtfk\MC\独立文件夹\versions\PoopSky 2026\mods\`
3. 确认 `mods` 里只有一个 `acechat` 模组（旧版请改名为 `.off` 留档，不要删除）；
4. 启动游戏，默认按 **K** 打开「角色卡工坊」。

首次启动会在游戏目录生成 `ACE_config/`：

```
ACE_config/
  client.json            全局聊天/音效等
  cards/<卡名>.json      每张角色卡
  stage/<工程>.json      剧本工程
  skins_slim/            皮肤（细）
  skins_classic/         皮肤（粗）
  portraits/             立绘图片
  filters/               用户滤镜 PNG
  deaths/                死亡覆盖图
  sounds/                自定义音效
  export/                导入导出
```

## 二、新界面结构

```
[角色卡：xxx ▸]        角色卡工坊 · SACS fork        [保存][重读]
                         [聊天] [形象] [文字]
                         [颜色] [管理] [剧本]
┌─ 实际样式预览（放大展示） ─┬─ 当前页字段（独立滚动） ─┐
│  形象框居中、聊天框在下     │  右侧滚动条              │
├─ 屏幕示意（16:9 / 960×540）─┤                          │
└─────────────────────────────┴──────────────────────────┘
```

- 每页独立滚动，切页记住各自位置；
- 顶部页签 `◆` + 黄色下划线标当前页；
- 「实际样式预览」只用于看样式/调色/文字，尺寸看右下「屏幕示意」；
- 取色、皮肤/立绘/音效预设/角色卡选择都在弹窗内完成，不跳旧界面；
- 所有控件改完自动保存（显示名 400ms 防抖，关界面会补写）。

## 三、六个页面现有功能

### 1. 聊天（客户端全局）

- 通讯框启用、玩家消息走原版、其它消息走原版、帧耗时调试；
- 屏幕显示行数 / 聊天界面行数 / 框宽 / 最大行数；
- X / Y 偏移、背景透明度、背景颜色；
- 右间距 / 左间距 / 名字最大宽 / 符号间距 / 左右内边距 / 上下内边距；
- 边框开关 / 颜色 / 粗细；
- **文字效果：原版阴影 / 描边 / 无**，描边颜色可调（默认描边）；
- 单条停留 / 停留下限 / 停留上限；
- 出现音效：预设选择 + 音量/音调/速度/淡入/淡出；
- 消失音效：开关/预设 + 音量/音调/速度/淡入/淡出；
- 总音量、试听、打开音效目录。

> 聊天框样式属于**当前客户端全局**，所有卡共用；卡文件不再保存 `chat`。

### 2. 形象（角色卡）

身份：

- 显示名（留空 = 卡名）、关联玩家名；
- 皮肤（**带头像预览的选择器**）、立绘文件；
- **半身像启用**（总开关）、**聊天时只显示文字**；
- **立绘图片模式（全局覆盖皮肤）** + 图片选择；
- 皮肤/立绘状态提示、重新扫描立绘目录、打开立绘目录。

外观：

- 照片模式、照片区高度、照片分隔线、外层皮肤、半身像缩放；
- **立绘缩放 / 立绘 X / 立绘 Y**；
- 整体缩放、宽 / 高、X / Y 偏移、皮肤 X / 皮肤 Y；
- 不透明度、亮度、颜色蒙版；
- 背景板开关/颜色/透明度/内边距；
- 面板颜色/透明度、边框颜色/粗细；
- **死亡覆盖**：开关、预设（NO SIGN / 只用 deaths 文件）、最大尺寸、缩放、X/Y 偏移、打开目录。

### 3. 文字（角色卡）

- 4 条内置元素：名字 / 生命 / 饥饿 / 护甲；
- 自定义元素：新增 / 复制 / 删除；
- 每条可改：内容、字号、X/Y、最大宽、水平/垂直对齐、阴影、显示、颜色；
- **安全重置位置**：只重排锚点/偏移，保留内容/颜色/字号；
- **默认名字颜色**（全局）；
- **本卡名字颜色**（跟卡；未命中条目时使用）；
- **名字颜色条目**：新增 / 改色 / 复制 / 删除 / 清空全部；
- 符号 `<<<` / `>>>` 跟随名字颜色，不再单独设色。

优先级：名字颜色条目 → 本卡名字颜色 → 全局默认名字颜色。

### 4. 颜色（角色卡）

- 调色：启用、亮度、对比、饱和、色相；
- 双色调：开关、暗色、亮色、强度；
- 滤镜：启用、滤镜选择（6 内置 + 已保存模板）、强度、混合模式、滤染色、亮度/对比/饱和/色相；
- **滤镜模板**：输入名字 → 保存 / 删除；「套用模板…」会连同调色、双色调、强度、混合一起恢复。

### 5. 管理

- 按发言者自动切卡、形象框常驻、形象框跟随聊天、NCR 兼容；
- 新建角色卡（复制当前卡）、重命名、删除（**两段确认**）、导出此卡；
- **导入角色卡**（从 `export/cards` 选文件）、**打开角色卡目录**；
- **在线玩家一键建卡**（没有卡就从默认卡复制并切换）；
- 导出配置、打开配置目录、旧版配置（对照用）。

### 6. 剧本

- 工程列表：新建 / 打开 / 复制 / 重命名 / 删除（两段确认）/ 导出 / 导入 / 打开目录；
- 进入画布后支持：触发卡、对话、间隔、逻辑门、结束卡；连线；文本编辑；撤销/重做；复制粘贴；
- 结束卡语义：
  - **可再次触发**：允许被新事件再次触发，冷却从演出结束算；
  - **只触发一次**：每人只触发一次；
  - 一次触发只演一遍，不会自动循环；
- 一次性事件（击杀/受伤/聊天/进退服等）对同一条规则只消费一次；`tick.every` / `lowHealth` 仍按冷却重复。

## 四、数据归属

| 数据 | 归属 |
|---|---|
| 聊天框样式（`chat` 段） | 当前客户端全局，所有卡共用，卡文件不保存 |
| 形象 / 文字元素 / 调色 / 滤镜 | 每张角色卡各自保存 |
| 名字颜色条目 / 本卡名字颜色 | 跟角色卡走（条目名默认 = 卡名） |
| 剧本工程 / 一次性记录 | `ACE_config/stage` / 存档 `acechat_stage.json` |

## 五、音效

- 预设：出现/消失各一组，由 `CommsSoundSynth` 合成；
- 自定义：把 `new_message.ogg|mp3|wav`、`message_gone.ogg|mp3|wav` 放进 `ACE_config/sounds/`，优先于预设，改文件不用重启；
- 演出换台词也会播放出现音效（与普通聊天共用开关/预设/参数）。

## 六、本版包含的质量修复

相对早期 0.1.3.x，本版包含四批质量批次（0.1.4.1~4.4）的内容：

- 滤镜的染色/亮度/对比/饱和/色相/特效颜色现在会写入 JSON，重启不丢；
- 卡、工程、状态、角色身份统一原子写；`client.json` 解析失败先备份为 `client.json.corrupt-时间戳`，不再静默覆盖；
- 启动自检：日志出现 `[acechat] selftest config-keys PASS`；
- 服务端资源请求做目录内校验/大小检查；工程解析/刷新捕获 RuntimeException，坏工程不会打崩 tick；
- 演出单包超过 UTF-8 上限时自动截断并记日志；
- 演出队列丢弃时不再误消费一次性事件信号；
- 旧配置界面/常驻/舞台编辑态强制使用正确角色的卡；
- 显示名与文字元素滑条写盘节流；调色改单线程烘焙 + 限流 + 释放旧纹理；
- 删除角色卡两段确认；导出配置/角色卡不覆盖同名文件。

## 七、尚未迁移 / 已知限制

以下仍建议走「管理 → 旧版配置（对照用）」：

- 打开角色卡目录里的批量导入（本版只支持单张选择导入）；
- 恢复默认（整卡 / 单元素 / 安全重置整卡）；
- 配置导入：剪贴板 / 粘贴 JSON / 从 `export` 文件导入；
- 名字颜色条目编辑玩家名 / UUID / 备注、在线玩家颜色列表；
- 锚点 X/Y 比例、锚点快捷预设；
- 预览区拖动卡片/文字、拖动缩放；
- 用户 PNG 滤镜直接选择、内置滤镜单独调色、滤镜目录重新扫描；
- 剧本规则页、触发器列表页、事件组时间线、调试页（画布可覆盖部分编辑）；
- 滤镜模板的“扫描”功能（保存/删除/套用已支持）。

其他注意：

- 模组是**客户端**模组，服务端不需要装；但多人服若要让所有玩家看到同一套演出资源，建议服务端也装同版本并保持资源一致；
- `mods` 里只能有一个 `acechat` jar；
- 推荐 GUI 缩放 2（16:9，960×540 逻辑分辨率）；
- 换 jar 前必须关闭游戏；热替换会崩服务端 tick；
- 改界面后回归：连续滚轮 20 次、来回切 6 页、拖滚动条，确认无重影。

## 八、排查

日志看 `[acechat]` 前缀：

- `selftest config-keys PASS`：配置字段自检通过；
- `卡工坊已打开（尺寸 W×H，预览区 w×h，屏幕示意 mw×mh）`：界面尺寸；
- `预览解析 name=… card=… bound=… skin=… tex=… real=…`：预览取了哪张卡/皮肤；
- `触发命中：project=… rule=… when=…`：演出规则命中；
- `调色烘焙失败/取不到皮肤像素`：调色暂时回退原图，通常数秒内自动重试；
- 崩溃先确认 `mods` 里只有一个 `acechat` jar，并附 `logs/latest.log`。
