## 分段版（按信息类型分段，无小标题）

ACE Chat 是一款把 Minecraft 原版聊天重构为「通讯终端」界面的客户端模组。

玩家发言以「发言人姓名 + 正文」的形式呈现于屏幕中上方的通讯框：姓名独占一行，正文居中，两端以 `<<<` / `>>>` 包裹；按字符折行，单行宽度由聊天框最大宽度决定。

右侧以角色卡展示发言人的皮肤或自定义立绘、边框、背景与文字元素，可按发言者自动切换；卡片的位置与尺寸可在预览页直接拖动调整并持久保存。

卡片内提供玩家名称、生命值、饥饿、护甲四条固定内置元素，以及可自由增删的自定义元素；支持 `%player_name%`、`%player_uuid%`、`%health%`、`%food%`、`%armor%`、`%ping%` 等占位符。字号、坐标与最大宽度随角色卡整体缩放，「重置位置」会依据当前形象框的几何自动重排。

叠加滤镜内置干扰线、噪点、暗角、双色调、点阵等模板，支持自定义 PNG 与正常／正片叠底／滤色／加法四种混合模式；通讯音效内置无线电风格，亦可使用自定义 `.mp3` 或 `.wav`。

全部数据集中于游戏主目录的 `ACE_config/`（主配置、角色卡、立绘、滤镜、死亡覆盖图、音效与导出目录）；旧版 `config/acechat/` 会在首次启动时自动搬迁并保留备份；角色卡与整体配置均支持导入导出。

模组以客户端渲染为主，服务器不安装也可完整使用；若服务器安装同一个 jar，则额外启用一条完全可选的数据通道，每秒下发玩家的血量、饥饿与护甲，使卡片上的数值对他人同样真实。

针对服务器使用 NoChatReports 等「会把玩家聊天改写为系统消息」的模组的环境，另提供 SPEC-ACE Chat 分支，可依据消息文本与在线玩家列表识别被改写的玩家聊天，并复用与真实玩家聊天相同的处理链。

模组支持 Minecraft 1.20.1（Forge 47.x，Java 17 及以上）与 1.21.1（NeoForge 21.1.x，Java 21）；内嵌的 MP3 解码库已做包重定位，避免与其它内嵌同一库的模组发生模块冲突。

本项目以 GPL-3.0-or-later 开源发布，允许收录进免费或收费整合包，但须保留作者与许可声明，并提供完整对应源码。

当前处于 Beta 一期测试阶段，欢迎反馈使用中遇到的问题。

## 精简版（一两句，适合视频简介／发布页首段）

ACE Chat 把 Minecraft 的聊天重做成一块「通讯终端」：发言以姓名与正文呈现于屏幕中上方，并在右侧以角色卡展示形象、状态与排版风格，附带叠加滤镜与通讯音效；模组以客户端运行为主，服务器可选安装以获得他人真实的血量、饥饿与护甲数据，另提供适配 NoChatReports 环境的 SPEC 分支，支持 1.20.1 Forge 与 1.21.1 NeoForge，以 GPL-3.0-or-later 开源。
