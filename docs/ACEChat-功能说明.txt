【三十二、本次更新记录：v0.032（文字元素预设重做 + 本体默认卡）】

    1. 【文字压进照片】根因：照片高是「卡片内高的百分比」，文字坐标却会被卡片缩放（默认几何约 ×0.89），
       以前把两者直接相加，名字会被画到照片里面去。现在按「照片像素底边 → 换算回元素坐标」重算：
       照片占 y 6..82、名字 85..94、自定义 99..106、生命·护甲 110..118、饥饿 122..129（卡内底边 132）。

       因此「安全重置 / 全部恢复为默认」之后文字尺寸不会忽然变大或变小。
  二、调整
    4. 【文字元素默认排版 = 逐行预设】名字 y=89 / 自定义 y=104 / 生命·护甲 y=117 / 饥饿 y=130；

【二十八、本次更新记录：顶部聊天框排版改版（名字独占首行 + 正文居中 + <<< >>>）】
  新形状：
      玩家名字                    ← 第一行：只有玩家名，整行居中
      <<< 正文开头……              ← 正文第一行：「<<<」与正文最左端在同一行
      正文中段……                  ← 中间行：按字符填满一行才换行
      正文结尾 >>>                ← 正文最后一行：「>>>」与正文最右端在同一行
  规则：
    · **每一行各自居中**（上一版是"多行左对齐成一段"）；
    · 单行最大宽度仍由**聊天框宽度**决定（扣掉左右内边距），超出就按字符换行，尽量往上堆；
    · 符号由「< >」改成「**<<< >>>**」，颜色与间隔仍由「符号颜色 / 符号间隔」控制；
    · 「最多显示行数」现在只限制**正文行**（名字行不计入）；
    · 正文超过行数上限时，最后一行用「… >>>」收尾；
    · 按 T 打开的原版聊天里，回放行仍是「名字 <正文>」—— 那是原版聊天界面，不走这套排版。
  验证：排版探针 11 个用例全部通过（实机那条消息、短消息、正好一行、多行、超长截断、长名字、
        窄框、英文、emoji、空正文、比符号还窄的退化框）；两平台无头测试 69 / 69 通过。

【二十五、本次更新记录：颜色蒙版 / 调色现在会直接染到形象框内的文字】
  现象：把「颜色蒙版」调成明显颜色、或把「调色」的亮度/对比/色相调离中性，
        形象框的**面板与照片会变，文字颜色却纹丝不动**。
  原因：文字元素之前是"靠 `RenderSystem.setShaderColor` 在画文字时染色"，
        而能不能作用到文字取决于渲染管线 —— 实测对文字元素看不到效果；
        另外「颜色蒙版」原本只参与滤镜图层的乘法，而滤镜图层是干扰线/噪点这类稀疏图案，
        给细线上色在文字上根本看不出来。
  修复：不再依赖 shader 染色，改成**把「颜色蒙版 × 整卡调色」直接乘进文字自己的颜色**再绘制
        （`CommsHud.applyElementTint` / `elementTint`），并撤掉之前"把 clearCardTint 挪到文字之后"
        的做法，保证只染一次。
        效果：调色变 → 文字跟着变；颜色蒙版变 → 文字跟着偏色；文字自身的 alpha（如半透明元素）保持不变。
  验证：新增 4 条无头断言（白色=不改色、红色蒙版只留红分量、半透明元素颜色同样成立…），
        两平台无头测试 69 / 69 通过；LinkCheck 全部引用可解析。

【二十四、本次更新记录：修好「关闭左下角玩家聊天」失效（按 T 的回放行摘不掉）】
  现象：把「左下角显示玩家聊天」关掉后，按 T 打开聊天框会看到玩家发言（这是设计：临时回放历史），
        但**关掉聊天框后那几行还留在左下角**，要等原版自然淡出才消失。
  原因：回放行是模组自己注入原版聊天的，注入时记了一份「身份证」用于稍后摘除：
          INJECTED.add(名字 + " <" + 正文 + ">")      → 例如 "AgnesTechyon <hi>"
        但真正注入的组件是 CommsConfig.chatLine(...) 生成的，符号两侧有「符号间距」折出来的空格：
          "AgnesTechyon < hi >"
        摘除时用 contains/startsWith 比对 → 对不上 → 摘不掉；而自查（anyRemains）用的是同一套判断
        → 认为"没有残留" → **连警告都不打**（静默失败，所以日志里什么异常都没有）。
  修复（1.20.1 与 1.21.1 同步）：
    ① 身份证改为从「实际注入的那个组件」取文本（getString()），格式怎么调都不会再对不上；
    ② 比对时忽略空格（兜底），以后改符号间距也不会复发。
  验证：新增 3 条无头断言（其中一条专门钉住"手拼格式 ≠ 实际文本"这个坑），
        两平台无头测试 65 / 65 通过；LinkCheck 全部引用可解析。
  效果：关掉聊天框后，回放的那几行**立刻**消失；左下角的新发言依旧不会进入原版聊天。

【二十三、本次更新记录：调色（颜色模板）现在也作用到形象框内的文字】
  现象：形象框里的文字（玩家名称 / Tasha / Joker3 / 生命 / 饥饿…）颜色不受「调色」影响，
        只有面板和照片会被染；调色改亮度、对比、色相时，文字看起来"没被处理"。
  原因：绘制顺序里，文字是在把调色**关掉**之后才画的（`clearCardTint()` 写在 `drawElementsSafe` 之前），
        所以文字只吃到了最后那层「滤镜图案」的颜色，没吃到调色本身。
        （「滤镜图案」本来就是最后铺满整个形象框的，一直覆盖着文字区，那部分没问题。）
  修复：三条绘制路径（死亡覆盖 / 立绘 / 皮肤半身像）统一改成「先画文字、再恢复调色」，
        于是文字和面板、照片一样吃到同一份调色。代码位置：`CommsHud.drawPortrait()`。
  验证：反编译新旧 jar 对比 `drawPortrait` 的调用顺序 ——
        旧：apply → clear clear → 文字 → apply apply → 滤镜；
        新：apply → 文字 → clear clear → apply apply → 滤镜（三条路径一致）。
  提示：如果某个实例看着"没被调色"，先看它的「调色」是不是中性值
        （亮度 100 / 对比 100 / 饱和度 100 / 色相 0 就等于没有调色）。

【二十一、已知兼容性情况：装了 NoChatReports 的整合包里，本模组会「看不到玩家聊天」】
  现象：在同一个实例里，模组加载正常、日志里也没有任何 [acechat] 报错，但顶部 HUD 迟迟不出现、
        玩家名字颜色也不生效，而玩家发言却照常显示在原版聊天里 —— 看起来就像「模组没生效」。
  原因：整合包里装了 NoChatReports（`mods\NoChatReports-*.jar`），它的
        `config\NoChatReports\NCR-Common.json` 里 `"convertToGameMessage": true` 会把玩家聊天
        先转换成「系统 / 游戏消息」再发给客户端。这类消息没有玩家发送者、被标记为系统消息，
        本模组按设计把它归入「其它信息」处理：放行给原版聊天、不进顶部 HUD、也不改名字颜色。
        （本模组只把「带玩家发送者的聊天」当成玩家聊天，这样才不会把服务器广播、成就、
          指令反馈误当成玩家发言。）

  三步自检（用来确认是不是这个原因）：
    1. 看 logs\latest.log：应有 `acechat 1.0.0-forge-1.20.1-r9`（模组已加载）与
       `[acechat] 已把平时屏幕的聊天高度压到约 N 行`（代码在跑），且没有任何 [acechat] 报错；
    2. 看日志里有没有 `[CHAT] <你的名字> 内容`：按「左下角显示玩家聊天=关」它本该被隐藏；

【一、安装】
1. 把 ACEChat-1.20.1-forge-1.0.0-forge-1.20.1-r9.jar 放进 .minecraft/mods（或整合包实例的 mods 目录）。
2. 只需客户端安装；单人/多人皆可（纯客户端渲染与本地记录，不需要服务端装）。
3. 首次启动会在 ACE_config/ 下自动创建素材目录与说明文件。
4. 覆盖升级：直接替换 mods 里的同名 jar 即可，配置与角色卡继续沿用（配置在 ACE_config/）。


【二、打开配置界面】
· 默认按键：K（可在「选项 → 控制 → 按键绑定」里改，分类为 ACEChat）
· 另有切换显示的开关键（默认 H）：按下会同时切换顶部 HUD 的显示状态并立即保存


【三、整体结构（侧边栏只有 4 个顶层项）】
角色卡 / 聊天框 / 导入导出 / 恢复默认

角色卡是「按玩家」的配置集合，三级菜单：
  ① 一级：选卡（★ 默认卡、当前在线玩家、本地已有卡）+ 新建/删除/打开卡目录
  ② 二级：点「编辑当前卡」进入，选择要改的功能（半身像 HUD / 预览与拖动 / 文字元素 /
      玩家名字颜色 / 叠加滤镜 / 调色）
  ③ 三级：具体参数的滑块与按钮；每页顶部都有「← 返回角色卡」可逐级退回

关键行为：
· 卡按【玩家名字】对应：某人的卡只在他/她发言并被显示时生效
· 渲染期间套用对方的卡，画完立刻还原「你正在编辑的卡」——所以在配置界面里编辑的
  永远是你选中的那张卡，不会被别人的卡顶掉
· 卡文件：ACE_config/cards/<玩家名>.json（每卡一个文件，立即写盘）
· 把 cards/ 整个目录复制走 = 完整备份；「用当前卡复制新建」可基于当前卡造新卡
· 可关闭「按显示玩家自动切卡」，此时始终使用你当前选中的卡


【四、聊天框】
· 聊天内容三段式渲染：玩家名 / 尖括号符号 / 正文，可分别设置
· 排版规则（正文过长时自动换行）：
  - 第一行 = 名字 +「<」+ 正文开头 → 名字、「<」、正文最左端一定在同一行
  - 最后一行 = 正文结尾 +「>」   → 「>」与正文最右端一定在同一行
  - 中间每行都填满才换行（内容尽量往上堆），单行上限 = 聊天框宽度 − 左右内边距
  - 多行时左对齐成一段（以最宽那行为基准居中），不再每行各自居中
  - 超过「最多显示几行」时，末行以「…」收尾并补上「>」
  - 中文 / emoji 按码点切行，不会把字切坏
· 符号与正文之间的间距：滑块 0~16 像素（默认 4），左右两侧同步
· 尖括号符号颜色可单独设置，默认【白色】；三处统一（左下角原版聊天 / 按 T 的历史行 / 顶部 HUD）
· 正文固定白色；改玩家名颜色时不会影响尖括号、正文与其它样式
· 聊天行数（两个滑块，都会改写原版对应的「聊天高度」选项；0 = 不干预）：
  - 「屏幕显示聊天行数」：没按 T 时左下角最多显示几行，默认 5
  - 「聊天栏最多显示行数」：按 T 打开时最多显示几行，默认 10（= 原版默认）
  只是少显示几行，不删任何数据：滚轮照样能翻到全部历史
· 两个显示位置可独立开关：
  - 顶部 HUD（默认开）
  - 左下角玩家聊天（默认关，避免和原版聊天重复）
  - 左下角其它信息（默认开）
· 不再出现「多人游戏里左下角残留一份」的问题
· 顶部 HUD 的折行由本模组接管（见上面的排版规则）；按 T 打开的原版聊天界面那几行
  仍是原版自己排版（左对齐、按空格断词），两边观感会略不同，这是原版界面，本模组不改它
· 文字元素系统：玩家名称 / 生命 / 饥饿 / 自定义文字，支持锚点、偏移、字号、颜色、阴影、
  最大宽度；【生命与饥饿是两个独立元素，默认各占一行，可分别摆放】
  内容支持占位符：
    %player_name%（玩家名）、%health%/%max_health%（生命，当前/最大）、
    %food%/%max_food%（饥饿，当前/最大）
· 血量与饥饿按【被显示的那位玩家】取值；自己准确，其他玩家/离线玩家显示 Unknown
  （客户端本来就拿不到别人的饥饿、护甲、延迟，这是协议限制）
· 文字元素【不会被裁剪】：即使摆到卡片外面也照常显示
· 「安全重置：把文字摆回框内」按钮：只重置锚点与偏移，保留内容/颜色/字号/阴影/最大宽度
· 「恢复默认元素集」按钮：重建内置元素（会覆盖对内置元素的改动），与上面那个分开


【五、半身像 HUD（形象框）】
三级菜单里按功能分成 5 页，每页有淡色分隔线 + 分组标题：

第 1 页 皮肤：形象框开关 / 常驻显示 / 跟随聊天 / 二层皮肤 / 照片内容（头像·半身·全身·全身像）/
             照片区高度 / 分隔线 / 人物大小 / 皮肤 X·Y 偏移 / 重新读取皮肤

第 3 页 背景板与显示效果：背板开关·颜色·不透明度·内边距 / 面板颜色·不透明度 /
             边框颜色·粗细 / 整卡不透明度 / 亮度 / 染色
第 4 页 死亡覆盖图：见第七节
第 5 页 卡片布局与位置：卡片宽·高 / 整体缩放（0.15× ~ 2.0×）/ 水平·垂直比例 / X·Y 微调

裁剪规则（超出背景板的部分不渲染）：
· 立绘：按卡片内区裁剪 —— 16:9 的图放进方形框，只会显示落在框内的那部分
· 皮肤各显示模式：同样裁剪，放大后不会溢出卡片、不会盖住别的 UI
· 文字元素：不裁剪
· 死亡覆盖图：不裁剪

边框说明：形象框本身有边框（颜色/粗细可调、可关）；背景板（背板）只有填充色，没有描边。


【六、调色与滤镜颜色】
调色（皮肤 / 立绘 / 滤镜）统一由同一套算法处理，参数：亮度 / 对比度 / 饱和度 / 色相 / 双色调：

| 对象          | 作用方式                              | 生效范围（亮度/对比度/饱和度/色相） |
| 皮肤          | 烘焙进皮肤贴图                        | 全部生效 |
| 立绘 PNG      | 按「文件 + 调色参数」烘焙，拖滑块即时生效 | 全部生效 |
| 滤镜层        | 烘焙进滤镜贴图                        | 全部生效 |
| 整张卡片      | 折成乘法色调套在卡片底色/边框/背板上   | 亮度、色相生效；对比度/饱和度需着色器，做不到 |
| 文字元素      | 不受整卡色调影响（保持清晰）           | — |

叠加滤镜新增能力（只影响滤镜这一层，不改变干扰线等特效的形状与强度）：
· 颜色蒙版：与滤镜图层做乘法叠加（白色＝不改色），可让干扰线偏红、暗角偏蓝等
· 本特效颜色：竖/横干扰线、噪点、暗角、双色调、点阵各自单独保存颜色
· 滤镜自身调色：亮度 30~180% / 对比度 30~200% / 饱和度 0~200% / 色相 -180~180°
· 原有：滤镜开关、滤镜选择（内置 + 自定义 PNG）、不透明度、混合模式（正常/正片叠底/滤色/加法）


【七、死亡覆盖图】
· 用途：某位玩家在发言显示期间死亡时，用一张图盖住他/她的形象框
· 放置：ACE_config/deaths/<玩家名>.png（只读取 1:1 正方形图；非正方形会被忽略并在日志提示一次）
· 内置预设：「NO SIGN」黑色方格 + 居中白字
· 可调：开关、是否使用预设、读取分辨率上限（64~1024，默认 256）、缩放、X·Y 偏移
· 死亡判定：优先解析原版死亡消息，其次用生命值/濒死状态兜底；自己死亡不触发
· 覆盖会一直保持到那条聊天消息消失/被替换；重生不会自动移除
· 滤镜与调色同样作用于这一层
· 注意：即使把「左下角显示其它信息」关掉（平时看不到死亡消息），死亡覆盖依然照常触发


【八、玩家名字颜色】
· 按玩家配置名字颜色（支持 UUID、备注）；配色板、复制/删除/清空条目
· 【三处统一】左下角原版聊天、按 T 打开的历史行、顶部 HUD 用的是同一份名单：
  - 名单里有这位玩家 → 用他/她的颜色
  - 名单里没有 → 用「玩家名初始颜色」（默认 #4C9AFF 蓝）
  所以三处的玩家名颜色永远一致，不会出现「一处蓝一处绿」
· 名单随角色卡保存：换卡即换配色（显示某位玩家时，用的是那张卡的名单）
· 只改名字那几个字：尖括号用「『<>』符号颜色」（默认白），正文固定白色，
  队标前缀（如 <[管理]名字> 里的 [管理]）颜色保持原样，点击/悬停提示也不会被破坏
· 名字颜色只在本地显示，不影响别人看到的画面


【九、预览与拖动】
· 预览区可直观看到形象框与聊天框位置
· 「拖动目标」闸门（默认只拖卡片）：
  - 只拖卡片：拖卡片移动、右下角缩放；按到文字上也不会误抓文字
  - 关闭拖动：预览区只用于查看
  - 只拖文字：只调整文字元素位置与字号
  - 全部可拖：两种都能拖（最灵活，也最容易误触）
· 锚点按钮：左上/右上/左下/右下/居中 一键归位


【十、导入导出】
· 导出配置：写入 ACE_config/export/client-export.json
· 复制到剪贴板 / 从剪贴板导入 / 粘贴 JSON 文本导入
· 导入会先把现有配置备份为 client.json.bak
· 导入框有保护：必须包含 "version" 字段才会尝试导入（防止误操作把配置重置）
· 「把当前角色卡导出到 cards 目录」：生成 _export_<卡名>.json
· 「打开角色卡目录」：方便整目录备份


【十一、素材目录（ACE_config/）】
· portraits/  立绘 PNG（放入后在界面点「重新扫描」）
· filters/    自定义滤镜 PNG（叠加在形象框上）
· deaths/     死亡覆盖图 <玩家名>.png
· sounds/     自定义音效（TTS/音频分层，按文件名匹配）
· cards/      角色卡，每卡一个 json
· export/     导出的配置
· 各目录都有 README.txt 说明格式


【十二、性能相关】
· 素材目录检查：整个会话只做一次（旧版曾每 tick 检查，每秒上百次磁盘调用，会明显掉帧）
· 立绘/滤镜贴图：按「文件 + 参数」缓存；参数变化有 500ms 节流，避免拖动时反复重烘焙
· 角色卡按玩家取卡：使用内存名单判定，不做磁盘 stat
· 聊天名字改色：只按「逐字符覆盖表」重建一次消息组件，不在渲染阶段做任何查找
· 滑块：拖动过程中即时生效，但只有松手才写盘
· 「重载渲染（重新烘焙）」按钮（半身像 HUD 第 1 页）：清空立绘/滤镜/死亡覆盖/皮肤调色的
  贴图缓存并重新读取。效果没正常显示时点一下即可强刷，不用重启游戏
· 「性能诊断（每秒打印耗时）」开关（聊天框页）：打开后 HUD 每帧超过 3ms 会在日志里
  每秒打印一行（含立绘/滤镜烘焙累计次数），用来定位掉帧来源；排查完请关掉


【十三、常见问题】
1. 形象框里没有文字
   → 先点「文字元素 → 安全重置：把文字摆回框内」；若某元素被手动设为不可见，需要重新打开
2. 立绘/滤镜改了颜色但画面没变
   → 点「重载渲染（重新烘焙）」；注意立绘/滤镜烘焙有 500ms 节流，拖动时会有轻微滞后
3. 形象框边框没了
   → 「半身像 HUD」第 3 页把「边框粗细」拖到 1 或 2（背景板本身没有描边）
4. 多人游戏里显示的不是我的卡
   → 卡是按玩家名对应的；确认对方名字下有卡文件，或关闭「按显示玩家自动切卡」
5. 掉帧
   → 打开「性能诊断」，把日志里 [acechat] 开头的行发出来；崩潰则看 logs/latest.log
6. 左下角看不到玩家发言了
   → 这是默认行为：「聊天框」页 →「左下角显示玩家聊天」默认关（玩家发言只在顶部 HUD 出现，
     按 T 仍能看到全部历史）。想让它也显示，把开关打开即可
7. 按 T 打开只显示几行
   → 「聊天框」页 →「聊天栏最多显示行数」（默认 10，= 原版默认）。设成 0 = 不干预，
     用原版设置；无论设多少，滚轮都能翻到全部历史
8. 想让平时左下角什么都不显示
   → 「左下角显示玩家聊天」和「左下角显示其它信息」两个开关都关掉即可（按 T 仍能看到全部历史）
10. 装了 NoChatReports 之类的模组后，玩家聊天不进顶部 HUD / 名字不变色
   → 见第【二十一】节：那类模组会把玩家聊天转成系统消息，本模组按设计不当成玩家聊天处理。
     最简单的是把它配置里的 `convertToGameMessage` 关掉再重启。

9. 顶部聊天框的长消息怎么换行
   → 第一行放「名字 + < + 正文开头」，之后每行填满换行，最后一行以「>」收尾；行数超过
     「聊天框最多显示几行」时末行出现「…」，说明还有内容没显示完，可以把「最多显示几行」调大
     （或把「宽度」调宽，一行能放更多字）


【十四、兼容说明】
· 与 FancyMenu、JEI 等常规客户端模组可共存（界面为自绘，控件布局会随窗口尺寸自适应）
· 名字颜色/尖括号颜色的改写只发生在你本地的聊天组件上，不改变原版聊天数据、也不影响别人看到的画面
· 与 Fabric 版、NeoForge 1.21 版功能一致（那两个版本尚在待移植状态）

      滤镜自身的色相偏移（只影响这一层）。取值范围 -180~180 度，默认 0。
  · 滤镜饱和度
      滤镜自身的饱和度（只影响这一层）。取值范围 0%~200%，默认 100%。
  · 模板名
      模板名：给当前这套滤镜参数起个名字，点「保存为模板」保存；同名会覆盖。
  · 颜色蒙版
      颜色蒙版：与滤镜图层做乘法叠加（白色 = 不改色）。配合下面的不透明度使用，可以让干扰线偏红、暗角偏蓝等等。
  · 双色调强度
      双色调强度：两色映射的混合比例。取值范围 0%~100%，默认 70%。
  · 调色亮度
      调色亮度：烘焙时的亮度倍率。取值范围 30%~180%，默认 100%。
  · 对比度
      对比度：绕中灰缩放，越大越硬朗。取值范围 30%~200%，默认 100%。
  · 双色调·暗部
      双色调的暗部颜色：画面最暗处映射到这个颜色。默认 深蓝灰 #14202B。
  · 双色调
      双色调：把画面按明暗映射到「暗色→亮色」两色渐变（档案卡/电影感常用）。取值范围 开/关，默认 关。
  · 启用调色
      启用调色：把皮肤贴图按下面的参数重新算一遍颜色，烘焙成一张缓存纹理后用（只烘一次，之后每帧零开销）。取值范围 开/关，默认 关。
  · 色相偏移
      色相偏移：整体色相旋转角度。取值范围 -180°~180°，默认 0°。取值范围 -180~180。
  · 双色调·亮部
      双色调的亮部颜色：画面最亮处映射到这个颜色。默认 绿色 #63E66B。
  · 饱和度
      饱和度：0% = 完全灰度，200% = 浓艳。默认 100%。取值范围 0%~200%。
  · 名字颜色
      名字颜色：只改变聊天框里这个玩家的名字颜色，点开可取色（含透明度）。默认 白色。
  · 备注
      备注：给当前名单记录添加说明。取值范围 任意文本，默认空。
  · 玩家 UUID
      玩家 UUID：优先按 UUID 精确匹配玩家。取值范围 UUID 或空，默认空。
  · 形象框常驻
      形象框常驻：打开后没有聊天时也一直显示（显示你自己的形象），优先于「跟随聊天栏隐藏」。关掉则与聊天同步——玩家发言时他的形象框出现，他最后一条消息自然消失后形象框一起消失。取值范围 开/关，默认 关。
  · 显示半身像背景板
      半身像背景板：半身像后面那块底板，关掉就只剩人物、面板底色仍会保留。取值范围 开/关，默认 开。
  · 背景板不透明度
      背景板不透明度：调低会让底板更透，人物更贴合后面。取值范围 0%~100%，默认 85%。
  · 背景板颜色
      背景板颜色：半身像后面那块底板的颜色，点开可取色。默认 近黑深蓝 #0B1016。
  · 背景板内缩
      背景板内缩：底板相对面板边缘留出的边距，也决定半身像的可用区域。取值范围 0~16 像素，默认 5。
  · 亮度
      亮度：只影响半身像贴图，100% 为原色，越低越暗。取值范围 30%~100%，默认 100%。
  · 人物大小
      人物大小：照片框里人物的大小。取值范围 40%~150%，默认 100%。调小可以让照片框的背景色更明显，也方便看取景。
  · 覆盖图读取分辨率
      覆盖图读取分辨率：deaths 目录里图片的读取/显示尺寸上限，最高 1024。取值范围 64~1024 像素，默认 256。
  · 覆盖图 X 偏移
      覆盖图 X 偏移：左右微调。取值范围 -200~200 像素，默认 0。
  · 覆盖图 Y 偏移
      覆盖图 Y 偏移：上下微调。取值范围 -200~200 像素，默认 0。
  · 死亡覆盖图
      死亡覆盖图：该玩家的聊天消息正在显示时他死亡 → 用覆盖图盖住他的形象；保留到那条消息消失或被新消息替换为止（复活不会立刻恢复）。只影响别人，自己不变。取值范围 开/关，默认 开。
  · 覆盖图缩放
      覆盖图缩放：死亡覆盖层的大小。取值范围 20%~400%，默认 100%。
  · 显示半身像
      显示半身像：控制半身像面板是否显示；没人发言时会显示你自己的半身像。取值范围 开/关，默认 开。
  · 跟随聊天栏隐藏
      跟随聊天栏隐藏：打开后只有在顶部聊天有消息时才显示形象框。取值范围 开/关，默认 关。
  · 面板高度
      面板高度：半身像面板的高度。取值范围 90~340 像素，默认 138。
  · 立绘 X 偏移
      立绘 X 偏移：立绘左右微调。取值范围 -200~200 像素，默认 0。
  · 立绘 Y 偏移
      立绘 Y 偏移：立绘上下微调。取值范围 -200~200 像素，默认 0。
  · 立绘缩放
      立绘缩放：自定义立绘的显示大小。取值范围 10%~400%，默认 100%。
  · 水平微调
      水平微调：在比例定位之后额外左右平移。取值范围 -300~300 像素，默认 0。
  · 垂直微调
      垂直微调：在比例定位之后额外上下平移。取值范围 -300~300 像素，默认 0。
  · 不透明度
      不透明度：调低会让整个半身像（含文字）变透明。取值范围 0%~100%，默认 100%。
  · 二层皮肤（帽子/外套/袖子/裤子）
      二层皮肤总开关：控制帽子、外套、袖子、裤子这几块外层贴图（原来的「显示帽子层」已并入这一项）。关掉就只剩一层皮肤，能明显看出区别。取值范围 开/关，默认 开。
  · 面板不透明度
      面板不透明度：调低会让面板底色更透。取值范围 0%~100%，默认 92%。
  · 面板颜色
      面板颜色：半身像面板底色的颜色，点开可取色。默认 深蓝灰 #1C2838。
  · 照片分隔线
      照片分隔线：照片框与文字区之间那条细线（颜色跟随边框色）。取值范围 开/关，默认 开。
  · 照片区高度
      照片区高度：照片框占卡片内部高度的比例，剩下的是下面的文字区。取值范围 30%~90%，默认 60%。
  · 照片内容
      照片内容：照片框里画什么，点一下切换。全身=完整人物（头+躯干+手臂+腿，默认叠上二层）；头肩=头+肩膀；半身=头+躯干+手臂；头像=只有头；完整贴图=把整张皮肤原图铺出来（能看到二层各块，但不合成在人物身上）。
  · 垂直位置
      垂直位置：面板在屏幕剩余空间里的垂直比例。取值范围 0%~100%，默认 8%（靠上）。
  · 整体缩放
      整体缩放：按比例放大或缩小整个面板。取值范围 0.5~2.0 倍，默认 1.0。
  · 皮肤 X 偏移
      皮肤/人物绘制的水平偏移，所有显示模式（头像/半身/全身）通用。取值范围 -120~120 像素，默认 0。
  · 皮肤 Y 偏移
      皮肤/人物绘制的垂直偏移，所有显示模式通用。取值范围 -120~120 像素，默认 0。
  · 染色
      染色：给半身像贴图整体叠一层颜色，点开可取色。默认 白色（不染色）。
  · 面板宽度
      面板宽度：半身像面板的宽度。取值范围 80~300 像素，默认 122。
  · 消失音淡入
      消失音淡入：开头渐强的时间。取值范围 0~200 毫秒，默认 0。
  · 消失音淡出
      消失音淡出：结尾渐弱的时间。取值范围 0~400 毫秒，默认 200。
  · 消失音音调
      消失音音调：只改变音高，**不会改变播放速度/时长**（相位式变调）。取值范围 50%~200%，默认 100%。
  · 消失音速度
      消失音速度：单独改变播放速度（会同时改变时长），与音调互相独立。取值范围 25%~400%，默认 100%。
  · 消失音音量
      消失音音量：单独控制「消息消失」音效的音量。取值范围 0%~200%，默认 100%。
  · 出现音淡入
      出现音淡入：开头渐强的时间。取值范围 0~200 毫秒，默认 0。
  · 出现音淡出
      出现音淡出：结尾渐弱的时间（对讲机感）。取值范围 0~400 毫秒，默认 120。
  · 出现音音调
      出现音音调：只改变音高，**不会改变播放速度/时长**（相位式变调）。取值范围 50%~200%，默认 100%。
  · 出现音速度
      出现音速度：单独改变播放速度（会同时改变时长），与音调互相独立。取值范围 25%~400%，默认 100%。
  · 出现音音量
      出现音音量：单独控制「新消息」音效的音量（再乘以下面的总音量）。取值范围 0%~200%，默认 100%。
