## 四、路径文档需要改的 7 处

| 位置 | 现文 | 应改为 |
|---|---|---|
| 〇 标题下 | “五个共享缓存” | “六个”，并把 `PortraitSource` 键写成 `UUID + name + mtime + TTL` |
| 二 生效链 | route 内判断“玩家消息走原版” | 注明该判断在 `ClientEvents`，`route` 只管 HUD 关闭/聊天类型/过滤 |
| 三 生效链 | 符号用 `chatSymbolColor` | 符号当前用名字色；`chatSymbolColor` 只用于原版回放（或修代码后改回） |
| 八 常见断点 | “模板名不存在会回退” | “模板名不存在 → 该帧不画滤镜” |
| 十三 生效链 | `drawMiniScreen：portraitRect 比例 + chat 偏移` | 实际是独立手算：宽/高/缩放对，X 偏移与右间距未接 |
| 十九 生效链 | “预热（缺资源 → AssetRequest）” | “预热只读本地/已下载资源；AssetRequest 由资源清单触发” |
| 二十一 矩阵 | 只有 `renderShowcase` | 补 `drawMiniScreen` 一行（工坊示意，需与 `chatRect/portraitRect` 同源） |
