# ACE Chat　功能与设计说明

> 一款面向 Minecraft 的**通讯终端风格聊天界面**模组。
> 当前版本：**v0.03-Beta**（Beta 一期测试）
> 支持：Minecraft 1.20.1（Forge 47.x）／1.21.1（NeoForge 21.1.x）
> 许可证：**GNU 通用公共许可证第 3 版或更高版本（GPL-3.0-or-later）**

---

## 一、模组定位

Minecraft 的原版聊天以"左下角滚动列表"呈现，信息密度低、辨识度弱，且难以承载角色化的表达。

ACE Chat 把聊天重新组织为一块**位于屏幕中上方的"通讯终端"**：玩家发言以"发言人姓名 + 正文"的形式呈现，配合右侧的**角色卡**（形象框）展示发言人的头像、着装与状态，让聊天从"文字流"变成"有形象的通讯界面"。在此之上，模组提供角色卡系统、立绘与叠加滤镜、自定义通讯音效，以及可自由排布的文字元素。

模组以**客户端渲染**为主：服务器不安装也能正常使用；若服务器愿意安装同一个 jar，模组会额外启用一条**可选的数据通道**，把玩家的血量、饥饿与护甲下发给客户端，使卡片上的数值对他人也真实可读。

## 二、核心功能

### 1. 顶部通讯框

- 发言人姓名独占一行，正文居中显示，两端以 `<<<` / `>>>` 包裹；
- 按**字符**折行（对中文等无空格语言友好），单行宽度由"聊天框最大宽度"决定，超出时自动换行；
- 支持"最多显示行数"，超出部分以省略号收尾，符号始终与正文两端同行；
- 姓名、正文、符号的颜色可分别设定，符号亦可与姓名同色；
- 多条消息按停留时间轮播，同一发言人连发时自动合并与顶替。

### 2. 角色卡（形象框）

- 支持**皮肤头像**与**自定义立绘**两种形象来源，可切换、可缩放、可偏移；
- 卡片可设定尺寸、边框颜色与宽度、背景色与不透明度、照片区高度，并支持整体缩放；
- **角色卡系统**：可为每位玩家保存一张卡片（名字颜色、显示名映射、文字元素排布等），并按发言者自动切换；
- 卡片位置、大小支持在预览页**直接拖动**调整，位置与几何设置会持久保存。

### 3. 文字元素

卡片内提供四条**固定内置元素**，均可在元素页单独编辑（显示开关、字号、对齐、坐标）：

| 元素 | 默认内容 | 说明 |
|---|---|---|
| 玩家名称 | `%player_name%` | 卡片标题位 |
| 生命值 | `生命 %health%/%max_health%` | 数值随服务端数据实时更新 |
| 饥饿 | `饥饿 %food%/%max_food%` | 同上 |
| 护甲 | `护甲 %armor%` | 同上 |

- 除内置元素外，可**自由增删**自定义文字元素，支持 `%player_name%`、`%player_uuid%`、`%health%`、`%food%`、`%armor%`、`%ping%`、`%dimension%`、`%world_time%` 等占位符；
- 「重置位置」会依据当前形象框几何（照片高度、内边距）**自动重排**，保证四条元素整齐落在照片下方、互不重叠；
- 文字元素的**字号、坐标与最大宽度会随形象框整体缩放**，因此放大或缩小卡片后，排版比例保持不变。

### 4. 立绘与叠加滤镜

- 立绘：将 PNG 放入 `ACE_config/portraits/`，在界面中重新扫描后即可选用；读取失败时自动回落到皮肤绘制；
- 滤镜：内置干扰线、噪点、暗角、双色调、点阵等模板，也支持自定义 PNG；
- 提供正常、正片叠底、滤色、加法四种混合模式，滤镜会覆盖整张卡片（含边框与文字），并可与角色卡自身的调色叠加。

### 5. 通讯音效

- 内置无线电风格提示音，可调音量、音调、速度与淡入淡出；
- 支持自定义 `new_message` / `message_gone` 音效（`.mp3` 或 `.wav`），放置在 `ACE_config/sounds/` 即可自动读取。

### 6. 配置与数据管理

- 全部数据集中在游戏主目录下的 **`ACE_config/`**：
  - `client.json`：主配置
  - `cards/`：角色卡（一人一文件）
  - `portraits/`、`filters/`、`deaths/`、`sounds/`：素材
  - `export/`、`export/cards/`：整体配置与角色卡的导入导出目录
- 旧版本的 `config/acechat/` 会在首次启动时**自动搬迁**到上述目录，原目录改名为备份保留，不删除任何文件；
- 支持"导入/导出 mod 整体配置"（带时间戳的文件、滚动选择框）与角色卡的单个文件导入。

## 三、兼容性与可选服务端

| 场景 | 表现 |
|---|---|
| 服务器**未安装**本模组 | 全部客户端功能正常；他人的血量/饥饿/护甲显示 `Unknown` |
| 服务器**安装**同一个 jar | 服务器每秒下发一次数值快照，卡片显示真实值 |
| 客户端未安装 | 原版体验，无任何影响 |

- 数据通道声明为**完全可选**，不会因为通道版本不符而阻断登录；
- 内嵌的 MP3 解码库（JLayer）已做**包重定位**，不会与其它同样内嵌该库的模组产生模块冲突；
- 网络协议只发送只读数据，不修改任何玩家存档或世界数据。

### SPEC 分支

针对服务器使用 **NoChatReports** 等"会把玩家聊天改写为系统消息"的模组的环境，另提供 **SPEC-ACE Chat** 分支：
它会尝试从消息文本中识别被改写的玩家聊天（`<名字> 正文`、`[名字] 正文`、`名字 » 正文` 等格式），并要求该名字**正是在线玩家**，认回后与真实玩家聊天走同一条处理链。
标准版与 SPEC 版 modId 相同，**同一实例只可安装其一**。

## 五、当前状态

模组仍处于**早期开发阶段**：功能项已基本齐备，但交互细节与兼容性仍在持续打磨。当前版本为 **Beta 一期测试**，欢迎通过 Issue 或社群反馈在使用中遇到的问题（附 `logs/latest.log` 与所用整合包名称能显著加快定位）。

后续改进方向：

1. 优化模组交互界面（设置页的分组、布局与说明）；
2. 修复更多兼容问题，尤其是与聊天类、HUD 类模组的共存；
3. 拓展兼容版本（更多 Minecraft 版本与加载器）；
4. 收敛已知缺陷，减少模组自身 bug。
