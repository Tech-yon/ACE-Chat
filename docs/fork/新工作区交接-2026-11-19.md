## 4. 构建

JDK：

```
C:\Users\Lenovo\AppData\Roaming\.minecraft\runtime\java-runtime-delta\bin
```

命令：

```powershell
powershell -ExecutionPolicy Bypass -File _build\SACS-1.21.1-Neoforge-fork\compile.ps1
powershell -ExecutionPolicy Bypass -File _build\SACS-1.21.1-Neoforge-fork\package.ps1
```

- `compile.ps1` 输出 `退出码: 0`、`错误条数: 0` 才算过；
- `package.ps1` 里的 `version="..."` 决定 jar 内版本号；
- 构建 jar 输出到 `_build/SACS-1.21.1-Neoforge-fork/SACS-1.21.1-Neoforge-fork.jar`；
- 安装用 `_build/SACS-1.21.1-Neoforge-fork/switch-to-fork.ps1`（会检查 java 进程与 latest.log 90 秒新鲜度）。

启动检查（无 PCL 命令行时的替代）：

- `_build/SACS-1.21.1-Neoforge-fork/launch-test.ps1` 从版本 JSON 直接拼 java 参数；
- cwd 是构建目录，日志/配置写在 `_build/.../logs`，不写 PoopSky 存档；
- 看到 `[acechat] selftest config-keys PASS`、`Sound engine started`、无 `[acechat]` 异常即通过；
- 检查完脚本会 `Stop-Process` 关游戏。

## 5. 发布流程（以后固定）

1. **改开发版**：在 `_r9work/SACS-1.21.1-Neoforge-fork` 改，开发版本号 `0.1.4.x`；
2. `compile.ps1` → `package.ps1`（`version="0.1.4.x"`），构建开发 jar；
3. **打发布包**：
   - 把 `package.ps1` 版本改成发布号（当前线 `0.1.3.xbeta`，本次 `0.1.3.3beta`）；
   - `compile.ps1` → `package.ps1`，得到发布 jar；
   - 把版本改回开发号 `0.1.4.x`，再 `package.ps1` 恢复开发 jar；
4. 新建 `SACS-ACECHAT-neoforge1.21.1-v<发布号>/`：
   - `SACS-ACECHAT-neoforge1.21.1-v<发布号>.jar`
   - `SACS-ACECHAT-neoforge1.21.1-v<发布号>.md`（从上一版复制并更新版本/新功能/限制）
5. **删除旧发布包**：工作区旧文件夹 + 旧 zip；仓库 `releases/` 旧目录；
6. 更新 `版本更新记录.md`（加发布条目与 jar/zip SHA），同步 `README-fork.md` 开发版本；
7. 同步 Git：
   - 源码 → `src-1.21.1-neoforge-fork-4/main/`
   - 文档 → `docs/fork/`
   - 发布包 → `releases/<新包>/`（jar `git add -f`）
   - 更新仓库根 `README.md` 发布/开发版本；
8. `git commit` + `git push origin main`；
9. 重新写一份本交接文件（日期/版本/哈希/待办）；
10. 压缩发布包 `SACS-ACECHAT-neoforge1.21.1-v<发布号>.zip`。

- 聊天描边可调粗细 `chatTextOutlineWidth`：
  - `0.0 ~ 3.0`，**0.1 步进**，默认 `1.0`，`0` = 不描边；

  - 锚点比例/预设、预览拖动、用户 PNG 滤镜/单独特效色/滤镜目录重扫；
