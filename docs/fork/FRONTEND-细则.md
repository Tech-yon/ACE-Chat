## 零、旧界面结构（对照用）

稳定版（以现有程序为准）：内部共 10 个页面（`TABS`），侧边栏只显示 5 个顶层——
角色卡 / 聊天框 / 剧本演出 / 导入导出 / 恢复默认；半身像、预览与拖动、名字、文字元素、滤镜
收进「角色卡」三级菜单。剧本演出下再分工程列表 / 事件组 / 规则 / 触发器 / 调试等子页。

新界面 = 6 页 + 顶栏（角色卡选择 / 保存 / 重读），每页独立滚动，左栏为「实际样式预览 + 屏幕示意」。

## 十一、验收顺序（按 6 页）

1. **聊天**：全部字段可改；改框宽/背景/颜色时预览同步；音效预设可选、能试听；
2. **形象**：皮肤/立绘弹窗自选；宽高/缩放/偏移/面板/边框/蒙版生效；预览放大且形象居中；
3. **文字**：4 内置 + 自定义增删改；名字颜色单条新增/改色/删除；符号颜色跟随名字（无独立设置）；
4. **颜色**：调色/双色调/滤镜参数全部可改；取色用内嵌面板；
5. **管理**：新建（复制）/重命名/删除/导出；NCR 开关；旧版配置入口；
6. **剧本**：工程列表完整，能进画布。

### 每次改 UI 的固定回归

- 连续滚轮 20 次、来回切 6 页、来回拖滚动条：**无重影**；
- 切卡后：预览/演出形象正确、聊天样式不变（全局）；
- 关界面重开：改动都在（自动保存 + 手动保存都验）。
