## 三、已确认的产品决策（不要再问）

1. 页签：聊天 / 形象 / 文字 / 颜色 / 管理 / 剧本。
2. `chat` 段＝客户端全局、优先级最高、所有卡通用；卡文件不写 `chat`。
3. 名字颜色跟卡走，绑定卡名（不是玩家名）。
4. 符号颜色放「文字」页。
5. 音效＝预设可选 + 自定义文件覆盖。
6. 新建卡＝复制当前卡。
7. 旧界面入口保留（对照用）。
8. 优先级：P0 归属/入口 → P1 卡数据分层 → P2 剧本页 → P3 其余。

## 四、下一轮开工前必须做的验证（让玩家做/看日志）

1. 「实际样式预览」：形象框居中、聊天框在下、整体明显放大；调宽/高/缩放跟着变。
2. 「屏幕示意」：显示 `GUI ≈ 当前分辨率`；改框宽/偏移/缩放时方块同步。
3. 演出：播一句应听到出现音；同一句不重复响；关「新消息音效」后不响。
4. 切卡：演出中切卡不再出现“上一个角色的皮肤/错位”；切回后形象正确。
5. 名字颜色：新增一条→改色只变一条→删掉即消失；演出里该卡发言名字变色。
6. 聊天全局：切卡后框宽/背景/颜色不变。
7. 自动保存：改完直接关界面，重开仍在；顶部“保存”可立即写盘。

> 若第 4 条仍错位：优先查 7.1 组（形象/皮肤）全部原因，尤其 `PortraitSource` 缓存与 `editingScreen` 下 `portraitOrSelf` 的卡来源；下一轮可做「舞台说话人始终用自己那张卡渲染」的强制覆盖。

## 六、构建 / 安装 / 回滚

```powershell
powershell -File _build\SACS-1.21.1-Neoforge-fork\compile.ps1
powershell -File _build\SACS-1.21.1-Neoforge-fork\package.ps1
powershell -File _build\SACS-1.21.1-Neoforge-fork\switch-to-fork.ps1
powershell -File _build\SACS-1.21.1-Neoforge-fork\switch-to-stable.ps1
```

- 切 jar 前**必须关游戏**；脚本会拒（`java/javaw` 进程或 `latest.log` 90 秒内仍在写）。
- 热替换会让服务端 tick 崩 `NoClassDefFoundError: ServerStageTriggers$Cached`，只能重启。
- 稳定版备份：mods 下 `SPEC-SACS-v0.032-neoforge.jar.off` 与三个 `.bak-*`；交付目录 canonical 在 `_r9work/deliver/SPEC-SACS-v0.032-neoforge/`。
